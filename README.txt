Code Academy Website

Project Overview

Code Academy is a responsive educational website created using HTML, Bootstrap 5, and CSS.

Technologies Used

- HTML5
- Bootstrap 5
- CSS3

Website Sections

1. Header & Navigation
2. Hero Section
3. Courses Section
4. About Us Section
5. Contact Section

Features

- Responsive design
- Bootstrap navigation bar
- Six course cards
- Bootstrap Grid layout
- Explore Courses button
- Mobile-friendly layout
